How evaluation links to the pipeline
┌─────────────────────────────────────────────────────────────────────┐
│                    RAGAS Evaluation Flow                            │
└─────────────────────────────────────────────────────────────────────┘

  eval_set.json          Your Existing Pipeline              RAGAS Metrics
  (questions)     ────►  (retriever + LLM)        ────►     (scores 0-1)
       │                       │                                  │
       │                       ▼                                  ▼
       │               ┌───────────────┐                  ┌──────────────┐
       │               │  1. Retriever │                  │ Faithfulness │
       │               │  (vectordb)   │                  │ Answer Rel.  │
       │               └───────┬───────┘                  │ Context Rel. │
       │                       │                          │ Context Prec.│
       │                       ▼                          │ Context Rec. │
       │               ┌───────────────┐                  └──────────────┘
       └──────────────►│  2. LLM Gen   │
                       │  (OpenAI)     │
                       └───────────────┘


RAGAS, it uses your entire pipeline:

Retriever → Searches your data/vectordb for relevant chunks
LLM Client → Generates answers using OpenAI API
RAGAS → Evaluates quality using LLM-as-judge


### to test RAGAS evaluation metrics

python main.py ragas --eval-file data/eval_set.json --metrics faithfulness



To Get Full Evaluation Working
Add OpenAI credits at https://platform.openai.com/settings/organization/billing/

Then run:


python main.py ragas --eval-file data/eval_set.json
